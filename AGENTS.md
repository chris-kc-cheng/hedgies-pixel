# Project Instructions

## Character animation

- Walking legs must move through natural poses with visible changes in limb position, bend, lift, foot placement, and weight transfer.
- Never represent leg movement by swapping limb colors while leaving the geometry in the same or nearly the same position.
- Judge animation at the final in-app sprite size and verify it with a rendered GIF before considering the artwork complete.
- Keep limb proportions appropriate to the animal; readable motion must not come from unnaturally lengthening the legs.

## Design documentation

- Keep `README.md` synchronized with the currently included character designs.
- Every included design must have a corresponding animated GIF linked from the README preview table.
- Regenerate and review the matching GIF whenever character artwork or animation frames change.
- Remove obsolete design previews and documentation when a character is removed.
